# Website Prompt: AG2K_TAMILAN — YouTube Creator Portfolio

Build a premium, modern, cinematic portfolio website for the Tamil YouTube content creator **AG2K_TAMILAN**.

**YouTube Channel:** https://www.youtube.com/@AG2K_TAMILAN

The website should present the creator's identity, videos, achievements, social media presence, and collaboration opportunities in a stylish, immersive experience. It should feel like a professional creator's personal brand website, not a generic business template.

## 1. Design Direction

Create a dark, cinematic gaming-inspired design with premium visuals.

- **Theme:** Modern gaming creator portfolio.
- **Background:** Deep black, charcoal, and dark grey.
- **Accent colors:** Electric purple and neon blue, with subtle white highlights.
- **Typography:** Bold modern fonts such as Space Grotesk, Inter, or Orbitron for selected headings.
- **Visual style:** Glassmorphism, soft glow effects, subtle gradients, rounded cards, cinematic shadows, and smooth transitions.
- **Layout:** Fully responsive, optimized for desktop, tablets, and mobile.
- **Animations:** Smooth scroll reveals, hover effects, animated counters, floating particles, and subtle background motion.
- Avoid excessive animations, clutter, and unnecessary loading screens.

## 2. Navigation Bar

Create a sticky, transparent navigation bar that becomes darker when scrolling.

Include:

- AG2K_TAMILAN logo or custom text-based brand mark.
- Home
- About
- Videos
- Achievements
- Socials
- Contact
- A highlighted **Subscribe on YouTube** button.

On mobile, use a clean animated hamburger menu.

## 3. Hero Section

Design a visually striking full-screen hero section.

Main heading:
**WELCOME TO MY WORLD**

Creator name:
**AG2K_TAMILAN**

Tagline:
_Gaming. Creativity. Tamil Passion._

Supporting text:
“Explore my gaming journey, latest videos, memorable moments, and everything happening on my creator journey.”

Buttons:

- WATCH MY VIDEOS
- SUBSCRIBE ON YOUTUBE

Link the buttons to the creator's actual YouTube channel and video section.

Visual elements:

- Large creator-name typography.
- Gaming-inspired abstract background with purple and blue lighting.
- A prominent creator avatar or character image, if provided.
- Animated neon outlines and subtle particles.
- A small scroll-down indicator.

Do not invent a real person’s appearance or use an unrelated creator's photograph. Make the hero portrait easy to replace with the creator's own image.

## 4. About Me Section

Heading: **WHO'S BEHIND THE CHANNEL?**

Create a premium two-column layout with a creator image on one side and text on the other.

Suggested introductory copy:

“Hey! I'm AG2K_TAMILAN, a Tamil content creator sharing my passion for gaming, entertainment, and creative content. This is my official space to showcase my videos, connect with my community, and document my journey as a creator.”

Include editable information fields for:

- Creator name
- Channel name
- Main content category
- Language
- Location, if the creator chooses to share it
- Started creating content
- Short personal introduction

Only display verified information. Do not fabricate subscriber counts, awards, personal details, or milestones.

## 5. Featured YouTube Videos

Heading: **LATEST VIDEOS**

Create a responsive grid of cinematic YouTube video cards.

Each card should include:

- Actual YouTube thumbnail.
- Video title.
- Upload date, if available.
- View count, if available.
- A play button with a subtle glow effect.
- Hover animation with a slight zoom.

Requirements:

- Use real videos from https://www.youtube.com/@AG2K_TAMILAN.
- Prefer the official YouTube Data API or a reliable, permitted video embed method.
- If live integration is unavailable, provide an editable list of YouTube video IDs.
- Clicking a card should open the video or play it in an accessible embedded modal.
- Add a **View All Videos** button linking to the official channel.

Never display fake videos or fabricated engagement statistics.

## 6. Creator Highlights

Heading: **MY CREATOR JOURNEY**

Create three or four elegant highlight cards, such as:

- Favorite Gaming Moments
- Special Uploads
- Community Highlights
- Memorable Milestones

Use editable content and images. Include subscriber milestones or achievements only when verified or supplied by the creator.

Use animated counters only for real data.

## 7. Content Categories

Heading: **WHAT YOU'LL FIND HERE**

Create visually distinctive cards for the creator's actual content categories.

Possible categories, to be customized after checking the channel:

- Gaming
- Minecraft
- Gameplay Highlights
- Challenges
- Tamil Entertainment

Each category should have its own background artwork, a short description, and a button that opens the relevant YouTube playlist or search page.

Do not assume that every category applies to the channel. Use the creator's actual uploads to determine the final categories.

## 8. Community Section

Heading: **JOIN THE COMMUNITY**

Supporting text:
“Be part of the journey. Watch the videos, share your thoughts, and stay connected for upcoming content.”

Include:

- Subscribe on YouTube button.
- Optional Discord community link.
- Other verified social media links.
- A stylish YouTube-themed visual.
- A short invitation to comment and support upcoming uploads.

Only show social accounts that the creator owns or has provided.

## 9. Achievements and Milestones

Heading: **EVERY STEP COUNTS**

Create a horizontal timeline or animated milestone cards.

Possible entries:

- Channel launch
- First memorable upload
- Subscriber milestones
- Special series
- Community achievements

Make all milestone entries editable. Use placeholders until actual dates and numbers are provided. Never invent achievements.

## 10. Contact and Collaboration

Heading: **LET'S CREATE SOMETHING AMAZING**

Supporting text:
“Have an idea for a collaboration, gaming project, or creator partnership? Get in touch.”

Include:

- Collaboration inquiry button.
- Business email field, configurable by the creator.
- Optional contact form with name, email, subject, and message.
- Clear validation and accessible success/error messages.

If a backend is implemented, validate and sanitize submissions server-side, protect against spam, and keep private contact information out of public frontend code.

Do not invent an email address.

## 11. Footer

Create a minimal, polished footer containing:

- AG2K_TAMILAN branding.
- Quick navigation links.
- YouTube channel link.
- Verified social links.
- Copyright year generated dynamically.
- A short tagline: “Made with passion. Powered by creativity.”

Add a floating YouTube subscribe icon where appropriate without covering important mobile content.

## 12. Technical Requirements

Preferred stack:

- React with TypeScript.
- Tailwind CSS.
- Framer Motion for animations.
- Lucide icons.
- Firebase only if a database, admin dashboard, or dynamic content management is genuinely required.

Requirements:

- Reusable, clean components.
- Responsive layouts.
- Fast loading and optimized images.
- Lazy-loaded video embeds.
- Semantic HTML and accessible navigation.
- Keyboard-accessible menus, buttons, and modals.
- SEO-friendly page titles and descriptions.
- Open Graph metadata for social sharing.
- Custom favicon featuring the AG2K_TAMILAN brand.
- Reduced-motion support.
- No broken links, placeholder buttons, or fake statistics.

Use the official YouTube channel URL:
https://www.youtube.com/@AG2K_TAMILAN

## 13. Final Visual Quality

The final result must look like a custom-designed portfolio for a serious Tamil YouTube creator.

Use generous spacing, strong typography, cinematic contrast, consistent card styling, polished hover states, and carefully balanced neon accents.

Do not make the website look like a standard template or an admin dashboard. Prioritize creator branding, video discovery, personality, and community engagement.

Build the complete, functional website with all sections, responsive styling, animations, and working navigation. If channel data is unavailable, use clearly labeled editable placeholders rather than fabricated information.
